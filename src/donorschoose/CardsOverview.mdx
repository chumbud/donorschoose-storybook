# Cards

Seven cards, and the differences between them are mostly about **where they
appear** rather than what they're made of. Two families cover most of it —
classroom projects and Essentials requests — plus a card for a funded project and
one for a school.

## Which card do I want?

- **[Project Card](?path=/docs/components-cards-project-card--docs)** — a
  classroom project with its funding progress bar, across active / almost-funded /
  funded / matched states. _Search results, project lists, teacher and school
  pages._
- **[Vertical Project Card](?path=/docs/components-cards-vertical-project-card--docs)** —
  the same project card in its compact "photo on top, title overlaid" layout.
  _"Nearby projects" grids._
- **[Map Card](?path=/docs/components-cards-map-card--docs)** — a classroom
  project sized for the map sidebar. _Discover local need → map sidebar._
- **[Essential Card](?path=/docs/components-cards-essential-card--docs)** — one
  classroom-basics item: real supply photo, price, "Add to cart". _"Help a teacher
  stock up" strips, Essentials lists._
- **[Map Essentials Card](?path=/docs/components-cards-map-essentials-card--docs)** —
  one Essentials item sized for the map sidebar. _Discover local need → map
  sidebar._
- **[Fully Funded Card](?path=/docs/components-cards-fully-funded-card--docs)** —
  a finished project: green "FULLY FUNDED!" pill, funding date, impact blurb,
  rosette. _"Fully funded projects at [school]"._
- **[School Card](?path=/docs/components-cards-school-card--docs)** — a school as
  a cream tile: location pill, school name, and either its teachers or a "Become a
  Founding Supporter" prompt. _Support a school._

## Picking between the close calls

**Project Card vs. Vertical Project Card** — one component, one prop. The vertical
card is `DCProjectCard` with `layout="vertical"`; reach for it when cards sit in a
grid and the photo should lead. Everything else about it (states, progress bar,
give box) behaves identically.

**Map Card vs. Project Card** — the map card is a separate, tighter component
built for the sidebar's width, not a variant of the project card. If you're not in
the map sidebar, you want the project card.

**Essential Card vs. Map Essentials Card** — same split as above: the plain
essential card is the full-size tile with the supply photo and its own add-to-cart
button; the map version is the compact row for the sidebar.

## Shared behavior

- **Money formatting** goes through `usd()` (`money.ts`) so every card renders
  amounts the same way — whole dollars, no cents.
- **Funding progress** on the project and fully-funded cards uses the same
  progress bar treatment as [Progress Bar](?path=/docs/components-progress-bar--docs).
- **Cart actions** (`onGive`, `Add to cart`) are callbacks — the cards don't own
  cart state. See [Cart](?path=/docs/components-cart--docs) for the mini-cart the
  additions land in.
